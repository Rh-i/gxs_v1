# omni3_chassis

> 代码：`omni3_chassis.hpp` / `omni3_chassis.cpp`　实例：`module_cfg.cpp` 的 `chassis`
> 布局图：`Docs/omni3/omni3_layout.py`（生成 png / svg，改布局从这里改）

三个全向轮互隔 120°，**前向 = M1/M2 的中线**；方位角从 +x 逆时针：M1 右前 30°、M2 左前 150°、M3 正后 270°。

## 符号约定

| 量 | 约定 |
| --- | --- |
| `v_x` | 右为正 (cm/s) |
| `v_y` | 前为正 (cm/s) |
| `ω` | 俯视逆时针为正 (rad/s) |
| 轮速 `v_i` | 沿该轮「正转」方向，单位 cm/s（轮面线速度，与 `DeviceMotor` 同量纲） |
| 正转 | 实测方向 = `d_i = (-sinθ_i, +cosθ_i)`（2026-10-29 上板核对，已整体取反） |

## 运动学

```
v_i = a_i·v_x + b_i·v_y + R·ω
```

| 轮 | θ | `a`（v_x 系数） | `b`（v_y 系数） | 自转项 |
| --- | --- | --- | --- | --- |
| M1 右前 | 30° | -0.500 | +0.866 | +R·ω |
| M2 左前 | 150° | -0.500 | -0.866 | +R·ω |
| M3 正后 | 270° | +1.000 | 0.000 | +R·ω |

- 自转系数三轮相同：120° 对称布局下自转只与 `R`（轮心到中心距离）有关，与三轮比例误差无关。
- 验证：前进 `v_y=+20` → `v = (+17.3, -17.3, 0)`，M1/M2 反向转、M3 不动；
  自转 `ω=+2 rad/s`、`R=10 cm` → `v = (+20, +20, +20)`，三轮同向。
- 单个轮子装反：改那台 `DeviceMotor::invert`，**不要**动本表。

## 接口

| 接口 | 说明 |
| --- | --- |
| `init()` | 断言三个电机已绑定、`R > 0`，然后 `stop()`。配置错属于代码错，直接停机 |
| `drive(vx, vy, ω)` | 先限 `ω` 到 `w_max`，算三轮目标，再逐轮限到 `±v_max`，写进各自的 `DeviceMotor::set_speed()` |
| `stop()` | 调三台 `DeviceMotor::stop()`：**短路制动**、模式回 STOP、清积分。**与 `drive(0,0,0)` 不同**，后者只是滑行到零速（还会因编码器抖动而嗡嗡响） |
| `wheel_target(i)` | 最近一次下发的目标，给测试对比用 |

本类**没有** `update()`：速度环、编码器、PWM 都在 `DeviceMotor` / `motor_task` 里，Module 只算目标。

## 限幅顺序与后果

1. `ω` 先限到 `±w_max` —— 自转项三轮共用，过大时会把三轮同时顶满，平移没余量；
2. 每轮合成结果再限到 `±v_max` —— 斜向平移 + 自转时可能超出单轮能力，被截断后**底盘方向会偏**，
   这是有意取舍（安全优先），所以测试时不要给「对角 + 自转」同时满速。

## 参数

| 参数 | 位置 | 说明 |
| --- | --- | --- |
| `wheel_radius_cm` | `module_cfg.cpp` 的 `CHASSIS_R_CM` | 轮心到中心距离，**待实测**；只影响自转标定 |
| `v_max_cm_s` | `module_cfg.cpp` 的 `CHASSIS_V_MAX_CM_S`（130） | 单轮限幅，必须 ≥ 遥控侧平移上限 |
| `w_max_rad_s` | `module_cfg.cpp` 的 `CHASSIS_W_MAX_RAD_S`（13） | 自转限幅，必须 ≥ 遥控侧 ω 上限（= V_MAX / R） |

## 测试

`User/App/test/omni3_test.cpp`（开关 `APP_TEST_OMNI3`）：每 2 s 切换 STOP / FWD / BACK / RIGHT / LEFT / SPIN+ / SPIN-，
200 ms 打印一行三轮目标与实测。判据：

| 段 | 三轮目标（`R=10 cm`） |
| --- | --- |
| FWD | `+17.3 / -17.3 / 0` |
| BACK | `-17.3 / +17.3 / 0` |
| RIGHT | `-10 / -10 / +20` |
| LEFT | `+10 / +10 / -20` |
| SPIN+ | `+20 / +20 / +20` |
| SPIN- | `-20 / -20 / -20` |

实测与目标的偏差只反映速度环调参结果，与运动学无关；三轮转向与图示不一致时先查 `DeviceMotor::invert`。
