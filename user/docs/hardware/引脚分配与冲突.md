# 引脚分配与冲突（STM32H723VGT6 / gxs_v1）

> 数据取自 `gxs_v1.ioc`；「代码实例」是 `User/Bsp/bsp_cfg.hpp` 里的全局实例。
> 旧板（DM_MC02：CAN×3、RS485、9 路串口、LCD/陀螺仪/电源使能）的引脚表随 `Example/User` 留档，
> 本板没有那些外设，`Bsp/bsp_can`、`Device/dji_motor_group`、`Device/device_emmv5_group`、
> `Device/device_buzzer`、`Module/corexy` 只作留档，不参与初始化。

## 定时器时钟

TIM 内核时钟 **275 MHz**（APB1/APB2 137.5 MHz × 2），全板统一，换算写进 `bsp_cfg.hpp` 的
`timer_clk_hz`：

- 舵机：`PSC = 274` → 1 MHz 计数，`ARR = 19999` → 50 Hz，**1 计数 = 1 µs**，脉宽可直接按 µs 填。
- 电机：`PSC = 0`、`ARR = 13749` → 275 MHz / 13750 = **20 kHz**（高于可听频段）。

同一定时器的两个通道共用计数器与 ARR，因此 TIM2 / TIM3 / TIM12 的两路必须同频。

## 串口 ×5（全部 DMA 收发）

| 外设    | TX   | RX   | 波特率 / 帧格式 | 代码实例      | 用途                          |
| ------- | ---- | ---- | --------------- | ------------- | ----------------------------- |
| USART2  | PA2  | PA3  | 230400 8N1      | `bsp_uart2`  | 预留                          |
| USART3  | PC10 | PC11 | 115200 8N1      | `bsp_uart3`  | 调试打印 / 调参波形           |
| UART4   | PA12 | PA11 | 100000 **9E2**  | `bsp_uart4`  | **SBUS**（R9DS 接收机，只收） |
| UART7   | PE8  | PE7  | 921600 8N1      | `bsp_uart7`  | 预留                          |
| USART10 | PE3  | PE2  | 921600 8N1      | `bsp_uart10` | 预留                          |

> RX 走 DMA + IDLE 断帧，缓冲区放在 `.dma_buffer.*` 段（DMA1/DMA2 访问不到 DTCM）。
> UART4 由 `DeviceR9ds` 解析，串口本身配置为 `UartMode::RxOnly`。

## PWM ×8

| 引脚 | 定时器通道    | 频率  | 代码实例      | 用途                    |
| ---- | ------------- | ----- | ------------- | ----------------------- |
| PB10 | TIM2_CH3      | 50 Hz | `bsp_pwm1`   | 舵机 `servo1`          |
| PB11 | TIM2_CH4      | 50 Hz | `bsp_pwm2`   | 舵机 `servo2`          |
| PB4  | TIM3_CH1      | 20 kHz | `bsp_pwm3`  | `motor1` IN1           |
| PB5  | TIM3_CH2      | 20 kHz | `bsp_pwm4`  | `motor1` IN2           |
| PB14 | TIM12_CH1     | 20 kHz | `bsp_pwm5`  | `motor3` IN2           |
| PB15 | TIM12_CH2     | 20 kHz | `bsp_pwm6`  | `motor3` IN1           |
| PB8  | TIM16_CH1     | 20 kHz | `bsp_pwm7`  | `motor2` IN1           |
| PB9  | TIM17_CH1     | 20 kHz | `bsp_pwm8`  | `motor2` IN2           |

> `bsp_init()` 里先清 CCR 再启动，**上电全部 0% 占空比**。
> 驱动板为 DRV8871：IN1 = IN2 = 1 → 短路制动（`DeviceMotor::stop()` 用的就是它），
> IN1 = IN2 = 0 → 滑行。

## 编码器 ×3（TIM Encoder TI12，4 倍频）

| 定时器 | A 相 | B 相 | 代码实例        | 对应电机 |
| ------ | ---- | ---- | --------------- | -------- |
| TIM1   | PA8  | PA9  | `bsp_encoder1` | `motor1` |
| TIM8   | PC6  | PC7  | `bsp_encoder2` | `motor2` |
| TIM4   | PD12 | PD13 | `bsp_encoder3` | `motor3` |

> CubeMX 已配 `TIM_ENCODERMODE_TI12`、`PSC = 0`、`ARR = 65535`；驱动只负责启动计数。
> 方向与机构反了改 `BspEncoder` 的 `.invert`，不要改接线。

## 复用与占用冲突

| 引脚          | 冲突                       | 本工程选择                                      |
| ------------- | -------------------------- | ----------------------------------------------- |
| PB4           | NJTRST / TIM3_CH1          | TIM3_CH1。只能用 SWD（4 线），JTAG 不可用       |
| PB8 / PB9     | I2C1_SCL/SDA / TIM16/17_CH1 | TIM16 / TIM17 PWM（`motor2`）                  |
| PA11 / PA12   | USB_OTG_HS DM/DP / UART4   | UART4（SBUS）                                   |
| PC10 / PC11   | SPI3 / USART3              | USART3                                          |
| TIM5          | 任意 PWM                   | **被 HAL 时基占用**（`stm32h7xx_hal_timebase_tim.c`），不可再用 |

## 本板没有的外设

CAN（FDCAN1~3）、RS485、USART1、UART5、UART8、UART9、SPI/陀螺仪、无源蜂鸣器、
电源使能（POWER_24V / POWER_5V）、QSPI Flash 均未在新板 `.ioc` 中配置。
