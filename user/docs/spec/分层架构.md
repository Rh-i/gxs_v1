# 分层架构

## 依赖方向

```txt
App（user/app）        任务创建与业务编排
 └─ Module（user/module）      多设备组合成的机构
     └─ Device（库 code/device）  单设备驱动
         └─ Protocol（库 code/protocol）  纯字节编解码
             └─ Bsp（库 code/bsp）       只认识外设，不认识业务
```

- 单向依赖：下层文件里不得出现上层的头文件。
- `Service` / `Algorithm`（库 `code/service`、`code/algorithm`）不属于主链，作为工具库贯穿各层。
- 跨层只用下一层暴露的全局实例，不直接写 HAL。

## 谁提供什么

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 外设驱动 `BspUartT` / `BspCanT` / `BspPwm` / `BspEncoder` / `BspKey` / `BspGpio` / `BspDwt` | 库 `code/bsp` | 库不含任何实例，也不认识具体板子 |
| 设备 `DeviceMotor` / `DeviceServo` / `DeviceR9dsT` / `DeviceEmmv5GroupT` / `DeviceBuzzer` / `DjiMotor` | 库 `code/device` | 同上 |
| 系统状态与后台任务 `system_init` / `system_start` / `sys_task` | 库 `code/service`、`code/tasks` | 由 `app_init()` 调用 |
| **实例**：`bsp_uart2/3/4/7/10`、`bsp_pwm1~8`、`bsp_encoder1~3`、`io1~3`、`led_b/g`、`breaker1`、`key_user`、`r9ds`、`servo1~2`、`motor1~3` | **本工程** `user/board/board_cfg.hpp` | 宿主唯一放实例的地方；DMA 实例必须在 `.dma_buffer` |
| `chassis` | 本工程 `user/module/module_cfg.hpp` | 三轮全向底盘 |
| 任务与入口 | 本工程 `user/app/` | `app_init()` 与三个业务任务 |

实例清单一律在 `user/board/board_instances.hpp` 用 X-macro 列出；**漏写不报错，只是运行期收不到数据**。

## 启动顺序

```txt
MX_FREERTOS_Init()            Core/Src/freertos.c（USER CODE Init 段）
 └─ app_init()                user/app/app_main.cpp
     ├─ system_init()         建 sys_state，创建 sys_task（10 ms）
     ├─ board_init()          DWT → 串口 → PWM → 编码器 → 设备，每路 configASSERT
     ├─ module_init()         chassis 校验（依赖已绑定的 motor1~3）
     ├─ system_start()        置运行位；有发送节点才建 can_tx_task
     └─ xTaskCreate(...)      key_task / motor_task / remote_task（自测任务由宏开关决定）
```

任务入口第一句都是 `sys_state.wait_running()`：初始化失败时任务自行退出，不会跑在半初始化的系统上。

## 统一接口

有外部数据源的类统一暴露带超时的 `update()`；纯计算 / 纯写寄存器的类不提供。

| 层 | 类 | 周期接口 | 说明 |
| --- | --- | --- | --- |
| Bsp | `BspUartT` | — | `receive(buf,size,timeout)` / `send(data,size,timeout)` |
| Bsp | `BspKey` | `update()` | 读 GPIO，无可等的「数据到达」 |
| Bsp | `BspPwm` / `BspGpio` / `BspDwt` / `BspEncoder` | — | 纯寄存器读写 / 计数 |
| Device | `DeviceMotor` | `update(dt_s)` | 读编码器 → PID → 写双路 PWM；`dt_s` 由调用方实测 |
| Device | `DeviceR9dsT` | `update(timeout_ms)` | 等串口字节最多 N ms |
| Device | `DeviceServo` | `update()` | 纯轨迹积分 |
| Module | `Omni3Chassis` | — | 由 `motor_task` 每拍推，自身无周期接口 |

约定：

1. 同一路串口的 `update()` 只能有一个任务调（接收缓冲区只有一个消费者）。
2. 带超时的 `update()` 只在第一次取数据时等，之后把已到的数据排空。
3. 不要在中断或高优先级实时循环里用非 0 超时。
