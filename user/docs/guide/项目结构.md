# 项目结构

## 顶层

```txt
Core/                     CubeMX 生成：HAL 初始化、main.c、freertos.c（只在 USER CODE 段内改）
Drivers/                  STM32 HAL 与 CMSIS
Middlewares/
├─ Third_Party/FreeRTOS   FreeRTOS 内核
└─ Third_Party/stm32-framework   业务库（submodule）：bsp / service / device / protocol / algorithm / tasks
user/                     本工程业务代码（见下节）
cmake/                    工具链文件与 CubeMX 的 CMake 集成
Flash/                    烧写脚本、SVD、udev 规则与调试配置
build/                    编译产物（不入库）
gxs_v1.ioc                CubeMX 工程文件，外设配置的唯一来源
CMakeLists.txt            CubeMX 生成一次后自行维护：末尾接入框架与 user/
CMakePresets.json         构建预设（Debug / Release）
startup_stm32h723xx.s     启动文件（含 .dma_buffer 段从 Flash 拷到 RAM_D1）
STM32H723xG_flash.ld      链接脚本（含 .dma_buffer 可加载段、.noinit）
.clangd / .clang-format   编辑器与格式化配置
.vscode/                  任务、调试与编辑器参数
```

## user/

```txt
user/
├─ app/                    应用层
│  ├─ app_main.{h,cpp}     入口 app_init()：system_init → board_init → module_init → system_start → 建任务
│  ├─ app_task.hpp         业务任务声明（key_task / motor_task / remote_task）
│  ├─ app_test.hpp         自测开关 APP_TEST_<域>_<功能>_ENABLED（默认全 0）
│  ├─ task/                key_task、motor_task、remote_task
│  └─ test/                按域分目录：chassis/、motor/、rc/
├─ board/                  板级配置（宿主唯一放实例的地方）
│  ├─ board_cfg.hpp        外设与设备实例（C++20 inline 变量）+ print_uart
│  ├─ board_cfg.cpp        board_init()：逐个 init()，失败 configASSERT 停机
│  ├─ board_instances.hpp  X-macro 实例清单（CAN / UART / SPI），供库展开
│  └─ hardware_config.h    任务优先级与栈深、CAN_RX/TX 等编译开关
├─ module/                 模块层
│  ├─ omni3_chassis.*      三轮全向底盘运动学
│  └─ module_cfg.*         chassis 实例与 module_init()
└─ docs/                   开发文档（索引见 README.md）
```

## 维护归属

| 条目 | 归属 | 说明 |
| --- | --- | --- |
| `Core/`、`startup_stm32h723xx.s`、`cmake/stm32cubemx/` | CubeMX 生成 | 只改 USER CODE 段；外设改动走 `gxs_v1.ioc` |
| `Drivers/`、`Middlewares/Third_Party/FreeRTOS` | ST 提供 | 不改 |
| `Middlewares/Third_Party/stm32-framework` | submodule | 改库要回库仓提交，再在这里 `git submodule update` |
| `user/` | 本工程维护 | 全部业务代码 |
| `gxs_v1.ioc` | 本工程维护 | 外设配置唯一来源 |
| `CMakeLists.txt`、`CMakePresets.json`、`STM32H723xG_flash.ld` | 本工程维护 | 见 [../build/链接脚本改动.md](../build/链接脚本改动.md) |
| `Flash/`、`user/docs/`、`.clangd`、`.vscode/` | 本工程维护 | 工具与文档 |
| `build/` | 生成产物 | 不入库 |

## 分层与依赖

```txt
user/app → user/module → 库内 device → 库内 bsp
```

上层可以使用下层，禁止反向依赖；`Service` / `Algorithm` 是贯穿各层的工具与算法，
`Protocol` 只做字节级编解码。分层细则见 [../spec/分层架构.md](../spec/分层架构.md)。

## 命名约定

文件名全小写加下划线，类名 PascalCase，实例名小写下划线。详见
[../spec/编码规范.md](../spec/编码规范.md)（与库内 `编码规范.md` 一致）。
