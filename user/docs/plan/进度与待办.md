# 进度与待办

## 已完成

- [x] DWT 驱动：`bsp_dwt`，内核 CYCCNT 计时，无外设、不依赖中断
- [x] UART 驱动：`BspUartT`，本板 5 路全 DMA 收发、流缓冲区、收发恢复
- [x] PWM 驱动：`bsp_pwm1~8`（舵机 50 Hz ×2、电机 20 kHz ×6）
- [x] 编码器驱动：`bsp_encoder`（TIM1 / TIM8 / TIM4，TI12 4 倍频）
- [x] 按键：`bsp_key`（200 ms 轮询消抖）+ `key_task` 双 LED 提示
- [x] 速度环：`DeviceMotor`（双 PWM H 桥 + 编码器 + `Pid` + JustFloat 波形）
- [x] 三全向轮底盘：`Omni3Chassis`（运动学）+ `motor_task`（1 kHz）+ `remote_task`（100 Hz R9DS）
- [x] 遥控：`DeviceR9ds`（UART4 SBUS，DMA）
- [x] 代码规范落地：分区横幅、命名、`Config` 构造模式、禁用 `friend`、`User/` 统一格式化基线
- [x] 文档体系：`Docs/` 目录、根 `README.md` 与开发规范

> ⚠️ 上列能力目前多为**编译通过**，底盘/速度环只做过初步实机调试，`CHASSIS_R_CM` 仍是占位值。

## 备注

- **备用代码**：`Bsp/bsp_can`（`BSP_CAN_ENABLED` 默认 0）、`Device/dji_motor_group`、
  `Device/device_emmv5_group`、`Device/device_buzzer`、`Module/corexy`、`Protocol/*`
  是从旧板搬入的留档/备用代码，当前**不建实例、不初始化**；换回旧板时按各文件头部注释打开对应开关。
- **BSP 封装边界（已定，不再讨论）**：`SPI` / `I2C` 一律**不做** BSP 封装——这几类通讯在本工程都是阻塞用法，
  直接由上层或库自行使用。
