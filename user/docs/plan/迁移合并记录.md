## 三、板级参数核对（旧 → 新，逐项比对过）

| 项 | 内容 |
| --- | --- |
| 串口 5 路 | USART2 230400、USART3 115200（打印）、UART4 100000 RxOnly（SBUS）、UART7 / USART10 921600，全 DMA |
| PWM 8 路 | TIM2_CH3/CH4 舵机 50 Hz（PSC 274 / ARR 19999）；TIM3_CH1/CH2、TIM12_CH1/CH2、TIM16_CH1、TIM17_CH1 电机 20 kHz（PSC 0 / ARR 13749） |
| 编码器 3 路 | TIM1、TIM8、TIM4，TI12 四倍频 |
| GPIO / 按键 | io1~3、led_b/g、breaker1、key_user（PC5，低有效，debounce 1 / 长按 5） |
| 电机 3 台 | 500 线 ×4 × 1:32、轮径 7 cm；`motor1` `invert=true`；PID 18/0.016、15/0.017、20/0.023（限幅 1000） |
| 舵机 2 台 | 500~2500 µs，行程 270° / 180°（第二台限速 300 dps、1500 dps²） |
| CAN | 本板无 FDCAN：`CAN_RX_ENABLE` / `CAN_TX_ENABLE` = 0，`BSP_CAN_INSTANCES` 为空 |

## 四、有意不合并 / 需要你知道的

1. **`freertos.c` 钩子体**改成调 `fault_on_*()`（见上），与库的 `configASSERT → fault_on_assert` 一致。
2. **未入库的留档代码**（`bsp_can`、`device_buzzer`、`device_emmv5_group`、`dji_motor_group`、
   `corexy`、`emmv5_protocol`、`corexy_protocol`）在迁移时随 `User/` 一起删除，按你的决定**不恢复**。
   要用来参考时从 `dm_mc02_lkm` 的历史里取。
3. **实机要自己核**：以上参数是按旧代码原样搬的，编译只能保证语法与链接；上电前确认波特率、
   定时器时钟 275 MHz、PWM 的 PSC/ARR 与 `gxs_v1.ioc` 一致。
4. 自测任务默认全关（`user/app/app_test.hpp` 里都是 0），要用时打开对应宏再编译。
